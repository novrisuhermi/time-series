# SARIMA Simulation & Case Studies

An interactive, self-contained HTML app for learning seasonal ARIMA models.

## Features

- Simulate seasonal and non-seasonal processes, including multiplicative SARIMA $(p,d,q)(P,D,Q)_s$, with user-chosen parameters
- Explore how seasonal parameters shape the time plot, ACF, and PACF (e.g., spikes at seasonal lags)
- Walk through real-data case studies following the Box–Jenkins procedure: identification, estimation, diagnostic checking (incl. Ljung–Box test), and forecasting

## How to Use

### Online

Open the app directly in your browser: **https://novrisuhermi-sarima.share.connect.posit.cloud**

### Offline

1. Download [`SARIMA_Simulation_Case_Studies.html`](SARIMA_Simulation_Case_Studies.html) (click the file, then the **Download raw file** button).
2. Open it in any modern web browser (Chrome, Edge, Firefox, Safari).

No installation, R, or internet connection is required.
