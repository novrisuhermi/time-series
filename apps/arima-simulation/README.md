# ARIMA Simulation & Case Studies

An interactive, self-contained HTML app for learning ARIMA models.

## Features

- Simulate AR, MA, ARMA, and ARIMA processes with user-chosen parameters
- Explore how parameters shape the time plot, ACF, and PACF
- Walk through real-data case studies following the Box–Jenkins procedure: identification, estimation, diagnostic checking (incl. Ljung–Box test), and forecasting

## How to Use

### Online

Open the app directly in your browser: **https://novrisuhermi-arima.share.connect.posit.cloud**

### Offline

1. Download [`ARIMA_Simulation_Case_Studies.html`](ARIMA_Simulation_Case_Studies.html) (click the file, then the **Download raw file** button).
2. Open it in any modern web browser (Chrome, Edge, Firefox, Safari).

No installation, R, or internet connection is required.
